# Features

1. **Workout library:** Browse a collection of workouts displayed as responsive cards. Each card shows the workout image, muscle groups, workout name, equipment, duration, calories and rating.

2. **Workout details:** Open any workout to see its full information, including difficulty, sets, reps, duration, calories, rating and step-by-step instructions.

3. **API-based workout data:** Workout information is loaded from the FitLog API instead of being hardcoded in the components.

4. **Workout plan and saved actions:** The interface includes options to add a workout to today's plan and save workouts for later.

5. **Responsive dark UI:** The application uses a dark theme with a responsive layout that works across desktop, tablet and mobile screen sizes.
